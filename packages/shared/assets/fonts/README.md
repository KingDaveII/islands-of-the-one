# Bitmap fonts

The client's two faces as pixel atlases, **converted from Silkscreen and Tiny5** (both SIL Open
Font License 1.1; the license texts are next to the sheets, `Silkscreen-OFL.txt` and
`Tiny5-OFL.txt`, and apply to these conversions too). The sources are the woff2 files in
`apps/client/public/fonts`.

| Files                                       | Face                                        | Use                    |
| ------------------------------------------- | ------------------------------------------- | ---------------------- |
| `silkscreen-8px.png`, `silkscreen-8px.json` | Silkscreen (The Silkscreen Project Authors) | labels and numbers     |
| `tiny5-8px.png`, `tiny5-8px.json`           | Tiny5 (The Tiny5 Project Authors)           | sentences, stats, lore |

Generated by `tools/bitmap-fonts.py` (Python, Pillow + fontTools): the unhinted outlines rendered
by FreeType's monochrome rasterizer at 8 px, so every glyph is on the font's own pixel grid with
no partial pixels, the same on every OS and browser. Do not edit the PNGs or the JSON by hand;
re-run the generator (`python3 tools/bitmap-fonts.py`, `--check` verifies the committed files).

- The PNG is white on transparent; the client tints it per color token and scales it by whole
  numbers for the 16 and 24 px sizes.
- The JSON lists every glyph: its box in the PNG (`x`, `y`, `w`, `h`), its left bearing from the
  pen (`xo`), its top from the top of the 8 px line box (`yo`) and its advance (`adv`). The
  `baseline` is the face's ascent row in that box (8 for Silkscreen, 7 for Tiny5). Neither face
  kerns.
- Charset: printable ASCII plus every character the game data and the scene strings use. A
  string with a character outside it draws nothing for that character; add it to the data or
  the scenes and re-run the generator (which fails if a face has no glyph for it).
- `docs/screenshots/m1-task8/font-sheets.png` is the contact sheet (every glyph at 4x in its
  line box) for ART to review.

`packages/shared/src/fonts.ts` reads the contracts and lays text out the way the client's
BitmapText does (`packages/shared/test/fonts.test.ts` renders golden images from them).
