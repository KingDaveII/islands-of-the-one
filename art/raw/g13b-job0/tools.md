# PixelLab MCP tools (g13b-job0)

Source: `tools/list` on `https://api.pixellab.ai/mcp` (server "PixelLab MCP Server" 0.2.0), fetched
2026-10-15. 102 tools. The full names, descriptions and input schemas are verbatim in `tools.json`.
In Claude Code they appear as `mcp__pixellab__<name>`.

How to read the columns:

- **Canvas sizes / frames** are the schema's own bounds (`min–max`, enum values, `def` = default). `?` means
  the schema gives no bound; several tools state their real limits only in the description (see `tools.json`).
- **Reference / style / palette inputs** lists every image, reference, style or palette parameter the schema takes.
- **Cost** quotes the cost sentences from the tool's description verbatim (trimmed to ~260 chars). "not stated"
  means the description gives no number; most list/get/delete calls are free bookkeeping. Measured cost for
  the one call this job made: see `manifest.json`.

Points that matter for the pilot:

- `create_character` only takes a south reference image (`reference_image_base64` / `_url`) in `mode="v3"`.
  The description quotes v3 at 2–9 generations, but this job's v3-with-reference call at 64×64 was
  quoted as, and charged, **1 generation** (see `manifest.json`).
- `get_balance` reports both the subscription generations and the separate USD credit balance.
- Pro-tier tools (`create_image_pro`, `edit_image`, `create_8_direction_object`, `create_ui_asset`,
  `create_character_state`, `transfer_outfit`, `inpaint_image`) are quoted at 10–25 generations each.
- `pixelart_workbench`, `vfx_workbench`, `save_to_asset`, `create_talking_gif`, `get_lip_sync`,
  `get_upload_url` and `wait_for_jobs` say they're free.
